# 📊 Relatório BI de Produção (Power BI)

## Sobre o Projeto
Este projeto consiste em um dashboard desenvolvido no **Power BI** para acompanhamento de indicadores de produção industrial.

O objetivo é fornecer uma visão rápida e visual do desempenho operacional, permitindo monitorar produtividade, qualidade e disponibilidade através de métricas consolidadas.

## Objetivos

- Desenvolver um dashboard interativo no Power BI;
- Aplicar conceitos de modelagem de dados;
- Criar KPIs relevantes para o setor produtivo;
- Praticar boas práticas de visualização de dados;
- Transformar dados brutos em informações úteis para tomada de decisão.

> ⚠️ Os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins educacionais.

---

## Indicadores Monitorados

### ✅ Produção Aprovada
Exibe o total de itens aprovados no processo produtivo.

### ❌ Produção Rejeitada
Exibe o total de itens rejeitados, auxiliando na análise de perdas e retrabalho.

### ⏱ Horas Produtivas
Quantidade total de horas efetivamente utilizadas na produção.

### ⏸ Horas Paradas
Quantidade de horas de parada operacional.

### 📈 Produção por Mês
Gráfico de colunas que apresenta a evolução da produção ao longo dos meses.

### 🎯 Disponibilidade
Indicador em formato de velocímetro (Gauge) para acompanhamento da disponibilidade operacional.

### ⭐ Qualidade
Indicador em formato de velocímetro (Gauge) para monitoramento da qualidade do processo produtivo.

## Aprendizados Obtidos

Durante o desenvolvimento deste dashboard, foi possível aprofundar conhecimentos em conceitos fundamentais de Business Intelligence (BI), principalmente relacionados à criação de indicadores de desempenho (KPIs).

### 📊 KPIs (Key Performance Indicators)

Um dos principais aprendizados foi entender que os KPIs variam de acordo com a área de negócio e os objetivos da organização.

Alguns exemplos:

- Produção → Quantidade produzida, disponibilidade e qualidade.
- Comercial → Faturamento, ticket médio e conversão de vendas.
- Logística → Tempo de entrega e nível de serviço.
- Recursos Humanos → Turnover e absenteísmo.

Dessa forma, a escolha dos indicadores deve sempre estar alinhada aos objetivos estratégicos da área analisada.

### 🎨 Design e Experiência do Usuário

Outro ponto importante foi compreender que um dashboard eficiente não depende apenas dos dados apresentados, mas também da forma como essas informações são exibidas.

Uma das ideias aplicadas durante o projeto foi:

> Um bom dashboard é 50% informação e 50% visual.

Por isso, foram considerados aspectos como:

- Hierarquia visual dos elementos;
- Escolha adequada de cores;
- Destaque para indicadores mais importantes;
- Organização intuitiva das informações;
- Facilidade de leitura e interpretação.

O objetivo foi criar um painel que permitisse ao usuário identificar rapidamente informações relevantes e tomar decisões de forma mais eficiente.
